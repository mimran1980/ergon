# Phase 2: SBE Codec Generation

> **Historical.** Written when the crate was `rusteron-cluster`; it is now crate `ergo-aeron-cluster` in `cluster/` (test harness: crate `ergo-aeron-cluster-test-support` in `cluster-test-support/`). Living doc: [2026-07-18-ergosbe-experimental-master-plan.md](2026-07-18-ergosbe-experimental-master-plan.md).

> Part of [master plan](./2026-07-17-rusteron-cluster-master.md)

**Goal:** Generate Rust SBE codecs from the pinned cluster schemas via sbe-tool 1.39.0, commit them, and write round-trip + golden-file tests for every client-relevant message type.

**Key uncertainty:** The sbe-tool 1.39.0 Rust generator (`RustGenerator.class`) is confirmed present but its output shape (module structure, API, naming conventions) is unknown until we run it. This plan handles both a usable output and a fallback.

**Gate:** Round-trip encode/decode tests pass for all generated message types. Golden-file byte comparison against Java-generated dumps matches.

---

## Task 2.1: First-run sbe-tool + assess output

**Files:**
- Create: `rusteron-cluster/src/codecs/mod.rs`
- Create: (generated) `rusteron-cluster/src/codecs/generated/*.rs`
- Create: `rusteron-cluster/src/codecs/generated/.checksum`

- [ ] **Run `just generate-cluster-codecs`**

```bash
just generate-cluster-codecs
```

- [ ] **Inspect the generated Rust files**

List what was generated and assess:

```bash
find rusteron-cluster/src/codecs/generated/ -name '*.rs' -exec wc -l {} \; | sort -n
```

Expected questions to answer by reading the output:
- Does sbe-tool produce a single file or multiple files?
- What is the module structure (a `lib.rs` with `mod` statements?)?
- What are the encode/decode API signatures? (`fn encode(&self, buf: &mut [u8]) -> Result<usize>` or similar?)
- Does it generate a `MessageHeader` struct?
- Are message types structs with typed fields or raw buffer wrappers?
- Does it use any external crates (zerocopy, byteorder)?

- [ ] **Decision point: is the generated output usable?**

**If USABLE** (well-formed Rust, readable, has encode/decode):
→ Continue to Task 2.2 (wrap + test).

**If UNUSABLE** (doesn't compile, missing critical types, panics):
→ Go to Task 2.3 (fallback: Java dump + hand-written codecs).

- [ ] **Commit generated codecs + checksum**

```bash
git add rusteron-cluster/src/codecs/
git commit -m "feat: add generated SBE cluster codecs (sbe-tool 1.39.0)"
```

## Task 2.2 (Happy Path): Codec module + round-trip tests

**Files:**
- Modify: `rusteron-cluster/src/codecs/mod.rs` (re-export generated types)
- Create: `rusteron-cluster/src/codecs/test_util.rs` (codec test helpers)
- Add tests to: `rusteron-cluster/src/codecs/mod.rs` or `rusteron-cluster/tests/codecs.rs`

- [ ] **Write `src/codecs/mod.rs`** — re-export generated types

```rust
//! Cluster SBE codecs generated by sbe-tool 1.39.0.
//!
//! Do not hand-edit files under `generated/`. Use `just generate-cluster-codecs`.

mod generated;
pub use generated::*;

#[cfg(test)]
mod tests;
mod test_util;
```

- [ ] **Write `src/codecs/test_util.rs`** — helpers

```rust
/// Assert that encoding then decoding a message produces the same field values.
pub fn roundtrip_encode_decode<T, F>(encode: F)
where
    F: FnOnce(&mut [u8]) -> usize,  // returns bytes written
{
    let mut buf = vec![0u8; 4096];
    let written = encode(&mut buf);
    let read_back = T::decode(&buf[..written])
        .expect("decode must succeed on encode output");
    // Field-level assertion is per-type; caller provides custom checks.
    // This helper just verifies encode→decode doesn't error.
}
```

- [ ] **Write per-message round-trip tests in `src/codecs/tests.rs`**

For each client-relevant message type, write a test that:
1. Constructs a message with known field values
2. Encodes to a byte buffer
3. Decodes from the byte buffer
4. Asserts all fields match the original values

Example for `SessionMessageHeader`:

```rust
#[test]
fn test_session_message_header_roundtrip() {
    let mut buf = vec![0u8; 256];
    let original = SessionMessageHeader {
        leadership_term_id: 42,
        cluster_session_id: 99,
        timestamp: 1234567890,
    };
    // encode
    let written = original.encode(&mut buf).expect("encode");
    // decode
    let decoded = SessionMessageHeader::decode(&buf[..written]).expect("decode");
    // assert
    assert_eq!(decoded.leadership_term_id, 42);
    assert_eq!(decoded.cluster_session_id, 99);
    assert_eq!(decoded.timestamp, 1234567890);
}
```

Write round-trip tests for ALL client-relevant messages:

| Message | Key fields |
|---|---|
| `SessionMessageHeader` | leadershipTermId, clusterSessionId, timestamp |
| `SessionEvent` | clusterSessionId, correlationId, leadershipTermId, leaderMemberId, code, version, detail |
| `SessionConnectRequest` | correlationId, responseStreamId, version, responseChannel, encodedCredentials |
| `SessionCloseRequest` | leadershipTermId, clusterSessionId |
| `SessionKeepAlive` | leadershipTermId, clusterSessionId |
| `Challenge` | correlationId, clusterSessionId, encodedChallenge |
| `ChallengeResponse` | correlationId, clusterSessionId, encodedCredentials |
| `NewLeaderEvent` | leadershipTermId, clusterSessionId, leaderMemberId, ingressEndpoints |
| `AdminRequest` | leadershipTermId, clusterSessionId, correlationId, requestType, payload |
| `AdminResponse` | clusterSessionId, correlationId, requestType, responseCode, message, payload |

- [ ] **Run codec tests**

```bash
cargo test -p rusteron-cluster --lib codecs
```

Expected: all round-trip tests pass.

- [ ] **Commit**

```bash
git add rusteron-cluster/src/codecs/
git commit -m "test: add SBE codec round-trip tests"
```

## Task 2.3 (Fallback): Java golden-file dump + hand-written codecs

**Only if Task 2.1 determined sbe-tool Rust output is unusable.**

- [ ] **Generate Java codecs and dump known test frames**

```bash
# Build cluster Java codecs from schema
cd rusteron-client/aeron
./gradlew :aeron-cluster:generateCodecs
# Write a small Java main that encodes each client message type with known values,
# dumps the raw bytes as hex to stdout, one message per line.
# (A temporary Java file in rusteron-java-test-support/src/test/java/)
```

- [ ] **Write a Java test dumper** (`rusteron-java-test-support/src/test/java/DumpGoldenFrames.java`)

```java
import io.aeron.cluster.codecs.*;
import org.agrona.concurrent.UnsafeBuffer;
import org.agrona.ExpandableArrayBuffer;

public class DumpGoldenFrames {
    public static void main(String[] args) {
        var buf = new ExpandableArrayBuffer(256);
        var msgHeader = new MessageHeaderEncoder().wrap(buf, 0)
            .blockLength(SessionMessageHeaderEncoder.BLOCK_LENGTH)
            .templateId(SessionMessageHeaderEncoder.TEMPLATE_ID)
            .schemaId(SessionMessageHeaderEncoder.SCHEMA_ID)
            .version(SessionMessageHeaderEncoder.SCHEMA_VERSION);
        new SessionMessageHeaderEncoder().wrap(buf, MessageHeaderEncoder.ENCODED_LENGTH)
            .leadershipTermId(42)
            .clusterSessionId(99)
            .timestamp(1234567890);
        System.out.println(bytesToHex(buf, 0, MessageHeaderEncoder.ENCODED_LENGTH + SessionMessageHeaderEncoder.BLOCK_LENGTH));
        // ... repeat for each message type
    }
}
```

- [ ] **Commit golden files** as `rusteron-cluster/src/codecs/testdata/<message_type>.hex`

- [ ] **Hand-write Rust structs** in `rusteron-cluster/src/codecs/manual/` with `encode()`/`decode()` that produce byte-identical output to the Java golden files.

- [ ] **Write byte-identity tests**:

```rust
#[test]
fn test_session_message_header_matches_java_golden() {
    let golden = include_bytes!("testdata/session_message_header.hex");
    let mut buf = vec![0u8; 256];
    let msg = SessionMessageHeader { leadership_term_id: 42, cluster_session_id: 99, timestamp: 1234567890 };
    let written = msg.encode(&mut buf).unwrap();
    assert_eq!(&buf[..written], &golden[..]);
}
```

- [ ] **Run tests**

```bash
cargo test -p rusteron-cluster --lib codecs
```
