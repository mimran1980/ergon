# `#[diagnostic::on_unimplemented]` on `SbeMessage` trait

Add the `#[diagnostic::on_unimplemented]` attribute to the generated `SbeMessage`
trait for clear compiler errors when non-SBE types are used in generic contexts.
Specified in DECISIONS.md §5.

**Status:** Not started

## Acceptance Criteria

- [ ] Generated `SbeMessage` trait has `#[diagnostic::on_unimplemented]`:
  ```rust
  #[diagnostic::on_unimplemented(
      message = "`{Self}` is not an SBE message type",
      note = "only types generated by ErgoSBE implement `SbeMessage`"
  )]
  ```
- [ ] Verified with a compile-fail test that the custom message appears
- [ ] Works on stable Rust (stable since 1.78)
- [ ] Golden file updated
- [ ] No impact on runtime performance

## Dependencies

None

- Small change with high impact on developer experience.
- DECISIONS.md §5 explicitly specifies this.
- Stable since Rust 1.78, well within MSRV.
