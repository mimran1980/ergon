# Auto-scaffold build.rs with println + create_dir_all

**Blocked by:** none (documentation + codegen helper)

The build.rs for generated SBE projects requires repetitive boilerplate: parse
the schema, call `Generator::generate()`, iterate over modules, create
directories, write files, and emit `cargo:rerun-if-changed` directives. All of
this should be auto-generated by ErgoSBE.

## What to generate

A template for `build.rs` that is either:
1. Emitted by `ergosbe` as a CLI feature (like `cargo ergosbe init`), or
2. Documented as copy-paste boilerplate in the user guide

The minimal template:

```rust
let generator = ergosbe::Generator::new(config);
let modules = generator.generate(&schema);
for m in modules.modules() {
    let dest = out_dir.join(&m.path);
    fs::create_dir_all(dest.parent().unwrap()).unwrap();
    fs::write(&dest, &m.source).unwrap();
    println!("cargo:rerun-if-changed={}", dest.display());
}
println!("cargo:rerun-if-changed=schemas/my-schema.xml");
```

## Acceptance criteria

- [ ] `GeneratedModule` fields (`path`, `source`) are documented
- [ ] Build script template in user guide
- [ ] `cargo:rerun-if-changed` directives emitted automatically or documented
- [ ] Directory creation handled (not left to caller)
