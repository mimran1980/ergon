# verdict could change with an upstream push and a failure could not be
# reproduced. The commit is the head of upstream `master` on 2026-11-05

# which predates the tests the Rust side mirrors. Bump it deliberately:
# re-run the script and update sbe/tests/fix_sbe_conformance_test.rs fixtures
# if the goldens moved.
