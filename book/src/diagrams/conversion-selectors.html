Both selectors match Quote.price: its type is the Decimal composite, and its path is "Quote.price".
FieldPath (0) beats NamedType (2): Quote.price takes the field_path mapping. Other Decimal fields keep the named_type one.
If field paths take every Decimal field, as in the book’s example schema (only Quote.price), a domain-type named_type has none left: “every field it matches takes a higher-precedence selector”.
Quote.price is a composite: the domain getter price() returns Result<T, _> (T from field_path), or Result<Option<T>, _> if its sinceVersion > 0.
